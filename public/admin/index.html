Logos, sponsors and stories

Logo & sponsors: replace your header and footer logos, adjust their size, upload sponsor logos, add website links, reorder sponsors and hide or remove them.

Pildid / Images: change the homepage hero, story photograph, About image and favicon. SEO: set page titles, descriptions and sharing images in English and Estonian. Each story also has its own SEO fields.

Two ways to edit

Online: upload the project to a public GitHub repository, enable GitHub Pages, then connect that repository to Pages CMS. The included configuration gives you English and Estonian fields, posts, route sources, site logos, sponsor logos with links, homepage photographs and SEO settings.

On your computer: run npm run dev from the project folder and open the printed editor address. Save changes directly to your files, then publish through GitHub.
